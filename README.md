# RotaCerta — Controle de Entregas

Projeto integrador acadêmico criado para praticar **HTML, CSS e JavaScript**.

## O que o projeto faz?
- Mostra um painel com total de entregas e quantidades por status.
- Permite cadastrar novas entregas.
- Permite pesquisar pelo cliente, destino ou número do pedido.
- Permite filtrar por status e atualizar uma entrega.
- Tem layout adaptável para celular e computador.

## Como executar
1. Baixe os três arquivos (`index.html`, `style.css` e `script.js`) para a mesma pasta.
2. Abra o arquivo `index.html` no navegador.
3. Clique em **Nova entrega** para cadastrar uma entrega de teste.

## Arquivos
- `index.html`: estrutura e textos da página.
- `style.css`: cores, fontes, espaçamentos e aparência visual.
- `script.js`: dados demonstrativos e ações da página.

## Importante
Os dados são demonstrativos. As entregas cadastradas ficam na memória da página e são apagadas ao recarregar. Este projeto não usa banco de dados nem coleta dados reais.
